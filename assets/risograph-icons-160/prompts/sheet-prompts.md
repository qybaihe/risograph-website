# Risograph Icons 160 Sheet Prompts

## Shared Base Prompt

Use case: stylized-concept icon library.
Asset type: 4x4 Risograph retro-print icon sprite sheet for app UI assets.
Primary request: Create exactly 16 separate simple Risograph-inspired icons on one pure green chroma-key sheet.
Layout: exactly 4 columns by 4 rows. Each cell contains one complete centered icon, equal visual size, generous padding, no overlaps, no cropping, no icon crossing a cell boundary.
Style: retro Risograph spot-color print, bold hand-cut shapes, chunky dark navy or black outlines, slightly imperfect color registration, visible halftone dots and grain inside the icon shapes only, screen-printed ink texture, playful but clean app-icon readability. Use warm red, vermilion, sunflower yellow, dusty sky blue, indigo, muted violet, coral pink, and off-white paper fill. Do not use green inside any icon.
Simplicity: broad everyday UI meanings, recognizable at 128px, one main object per cell for early sheets, gradually more lively combinations in later sheets.
Background: perfectly flat solid #00ff00 chroma-key background. The background must be one uniform color with no shadows, no gradients, no texture, no paper grain, no reflections, and no lighting variation.
Output constraints: no labels, no readable text, no watermark, no realistic cast shadows, no 3D rendering, no photorealism, no full scene backgrounds.
