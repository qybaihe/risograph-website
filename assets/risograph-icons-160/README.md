# Risograph Icons 160

First batch of Risograph retro-print app icons.

- `sheets/`: 10 generated 4x4 green-screen sprite sheets, 16 icons per sheet.
- `icons/`: 160 transparent 512x512 PNG exports sliced from the sheets.
- `prompts/sheet-prompts.md`: source prompts and slot definitions.
- `wiki/icon-wiki.tsv`: stable slug, sheet, and slot lookup table.
- `preview-risograph-icons-160.jpg`: preview of the 10 source sheets.
- `preview-transparent-icons-160.jpg`: preview of the transparent icon exports.

Style anchors: chunky dark outlines, spot-color Risograph palette, subtle offset registration, halftone grain inside icon bodies, flat chroma-key sheet background, no readable labels.
