# Website Patterns

## Landing Page

- Use a warm paper base and a first-viewport product signal.
- Frame the product screenshot or offer like a printed poster, not a generic card.
- Use one clear primary CTA with dark outline and restrained offset color shadow.
- Let a hint of the next section peek into the first viewport.

## Dashboard

- Keep dense workflows intact.
- Use Risograph tokens for section headers, active nav, status badges, empty states, and top-level modules.
- Keep tables compact, readable, and high contrast.
- Avoid texture inside table cells and form controls.

## SaaS Tool or Editor

- Preserve familiar tool controls and icon metaphors.
- Use bundled icons for empty panels, command categories, template cards, or onboarding.
- Keep toolbars fixed-size and avoid hover states that shift layout.
- Use compact outlined controls rather than oversized editorial posters.

## Portfolio or Creative Site

- Use larger headings, asymmetric poster composition, and richer print texture.
- Pair Risograph icons with real work samples or product imagery.
- Avoid making decorative print marks more important than the actual work.

## Forms and Checkout

- Prioritize trust and clarity.
- Use off-white panels, strong borders, clear focus rings, and small section icons.
- Keep error/warning states familiar.
- Avoid decorative halftone backgrounds inside inputs.

## Empty States

- Choose one strong icon from the bundled library.
- Use a short heading, one sentence, and one clear action.
- Add a spot-color circle or halftone block behind the icon only if it does not reduce legibility.

## Mobile

- Reduce texture and print marks before reducing content.
- Keep icon sizes consistent.
- Prefer stacked poster bands and simple offset accents.
- Check that long words and button labels fit without overlap.
